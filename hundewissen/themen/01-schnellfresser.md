# Video 1: „Ist dein Hund ein Schnellfresser?“ – Themen-Bilder (ChatGPT, 23.11.)
Hochladen: `renders/aussie-stil-neu.png`. Schon vorhandene passende Posen: gierig, satt, krank, schnueffelnd, sitz-leckerli, tisch.

## Bild A – Hund + Thema
```
Zeichne genau diesen Hund (Australian Shepherd, blue merle, gleicher Zeichenstil, gleiche Farben, gleiche Linien) in 6 neuen Szenen nebeneinander auf reinweißem Hintergrund, ohne Schatten, ohne Text, jede Szene mit Abstand:
1. schlingt hastig, der Napf ist schon leer, Krümel am Maul
2. hat danach einen aufgeblähten Bauch und schaut unwohl
3. würgt leicht, Ohren hängen, ihm ist übel
4. frisst langsam und konzentriert aus einem Anti-Schling-Napf mit Labyrinth
5. sucht mit der Nase Futter in einem Schnüffelteppich
6. sitzt ruhig und geduldig vor seinem vollen Napf und wartet
```

## Bild B – Hilfsmittel (ohne Hund)
```
Zeichne im gleichen Zeichenstil wie dieses Bild (gleiche Linien, gleiche warme Farben) 6 einzelne Gegenstände nebeneinander auf reinweißem Hintergrund, ohne Schatten, ohne Text, mit Abstand:
1. ein Anti-Schling-Napf mit Labyrinth-Muster, mit Trockenfutter gefüllt
2. ein runder Schnüffelteppich aus Stoffstreifen, Futterstücke darin versteckt
3. ein Futterball (Spielball mit Loch), Futter fällt heraus
4. ein Muffinblech, in jeder Mulde etwas Trockenfutter
5. ein normaler Edelstahl-Napf randvoll mit Trockenfutter
6. eine Stoppuhr
```

## Bild C – Erklär-Bilder (ohne Hund)
```
Zeichne im gleichen Zeichenstil wie dieses Bild (gleiche Linien, gleiche warme Farben) 6 einzelne Erklär-Bilder nebeneinander auf reinweißem Hintergrund, ohne Schatten, ohne Text, mit Abstand:
1. ein einfacher, freundlicher Hundemagen (wie im Schulbuch) gefüllt mit Futter und vielen Luftblasen
2. derselbe Magen, aber verdreht und rot leuchtend als Warnung
3. eine große Futterportion, daneben ein Pfeil zu drei kleinen Portionen
4. ein Tierarzt-Koffer mit rotem Kreuz
5. eine Wasserschale mit frischem Wasser
6. ein Ausrufezeichen in einem orangen Warndreieck
```
