# Rollball – ChatGPT-Bilder (24.11.2026)

2 Bilder mit je 6 Szenen = 12 Bilder. In ChatGPT **beide Dateien hochladen**:
`renders/aussie-stil-neu.png` (Hund + Zeichenstil) und `renders/rollball-produkt.jpg` (das Spielzeug).
Fertige Bilder an Claude schicken → `python3 scripts/posen_schneiden.py <bild> name1 … name6` → `brand/aussie/`.

## Bild A – Hund mit dem Ball (Namen: ball-maul, ball-jagen, ball-stupsen, ball-zerren, welpe-ball, ball-schlafen)
```
Bild 1 zeigt unseren Hund, Bild 2 unser Spielzeug (oranger Ball mit zwei orangen Seilen und weißem Ring).
Zeichne genau diesen Hund (Australian Shepherd, blue merle, gleicher Zeichenstil, gleiche Farben, gleiche Linien) mit genau diesem Spielzeug aus Bild 2 in 6 Szenen nebeneinander auf reinweißem Hintergrund, ohne Schatten, ohne Text, jede Szene mit Abstand:
1. trägt das Spielzeug stolz an den Seilen im Maul
2. rennt dem rollenden Spielzeug fröhlich hinterher
3. liegt auf dem Bauch und stupst das Spielzeug mit der Nase an
4. zerrt spielerisch an einem Seil des Spielzeugs
5. als kleiner Welpe, spielt neugierig mit dem Spielzeug
6. liegt müde und glücklich eingerollt neben dem Spielzeug und schläft
```

## Bild B – Geschenk, Lieferung, Vergleich (Namen: geschenk, weihnachtsbaum, paket, normaler-ball, usb, sterne)
```
Bild 1 zeigt unseren Hund, Bild 2 unser Spielzeug (oranger Ball mit zwei orangen Seilen und weißem Ring).
Zeichne im gleichen Zeichenstil (gleiche Linien, gleiche warme Farben) 6 Szenen nebeneinander auf reinweißem Hintergrund, ohne Schatten, ohne Text, jede Szene mit Abstand:
1. genau dieser Hund sitzt neben einem offenen Geschenk mit oranger Schleife, darin liegt das Spielzeug aus Bild 2
2. genau dieser Hund sitzt vor einem kleinen Weihnachtsbaum, darunter liegt das Spielzeug aus Bild 2
3. genau dieser Hund schaut neugierig auf ein Paket an der Haustür
4. genau dieser Hund liegt gelangweilt neben einem normalen gelben Tennisball
5. nur das Spielzeug aus Bild 2, ein weißes USB-Kabel steckt darin, ohne Hund
6. vier goldene Sterne in einer Reihe, ohne Hund
```

## Wofür
- v1 Allein: ball-jagen (Produkt), ball-schlafen (Ende)
- v2 Normale Bälle: normaler-ball (Einstieg), ball-zerren (Seile), welpe-ball (kleine Hunde)
- v3 Geschenk: geschenk (Einstieg), weihnachtsbaum, paket (Lieferung)
- v4 Kauen: ball-stupsen (antippen), ball-maul (beschäftigt)
- v5 Black Friday: sterne (4 Sterne), usb, ball-maul
