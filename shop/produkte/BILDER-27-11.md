# ChatGPT-Aufträge 27.11.2026 – LED-Geschirr + Pflegeset

Je Bild 6 Ansichten. Fertige Bilder an Claude → `scripts/produkte_schneiden.py` bzw. `scripts/posen_schneiden.py`.

## Bild 1 – LED-Geschirr (hochladen: Shop-Foto vom grünen Geschirr)
```
Erstelle ein fotorealistisches Produktbild von genau diesem Hundegeschirr (schwarzes Netzgewebe, reflektierende Nähte, leuchtende LED-Streifen, runder Ein/Aus-Knopf auf der Brust). 6 Ansichten nebeneinander in 2 Reihen auf reinweißem Hintergrund, ohne Schatten, ohne Text, ohne Logo, jede Ansicht mit Abstand:
1. von vorne, LED leuchtet grün
2. von vorne, LED leuchtet rot
3. von vorne, LED leuchtet blau
4. schräg von der Seite, LED aus (nur schwarz)
5. Nahaufnahme vom Ein/Aus-Knopf mit kleinem USB-Ladekabel
6. von hinten mit dem Griff und dem Metallring für die Leine, LED leuchtet grün
```

## Bild 2 – Pflegeset (hochladen: Shop-Foto Nr. 1 mit dem Gerät)
```
Erstelle ein fotorealistisches Produktbild von genau diesem Hunde-Pflegeset mit Staubsauger (weißes Gerät mit blauem Griff, grauer Schlauch, weißes Handstück, Aufsätze). 6 Ansichten nebeneinander in 2 Reihen auf reinweißem Hintergrund, ohne Schatten, ohne Text, ohne Logo, ohne Tiere, ohne Medaillen, jede Ansicht mit Abstand:
1. das ganze Gerät mit Schlauch und Handstück
2. das Handstück mit der Bürste vorne dran
3. die Schermaschine einzeln
4. der Krallen-Schleifer einzeln
5. alle Aufsätze ordentlich nebeneinander auf dem weißen Halter
6. der Auffangbehälter voller Hundehaare
```

## Bild 3 – Unser Aussie mit beiden Produkten (hochladen: `renders/aussie-stil-neu.png` + Geschirr-Foto + Pflegeset-Foto)
```
Bild 1 zeigt unseren Hund. Bild 2 ist ein leuchtendes Hundegeschirr, Bild 3 ein Hunde-Pflegeset mit Staubsauger.
Zeichne genau diesen Hund (Australian Shepherd, blue merle, gleicher Zeichenstil, gleiche Farben, gleiche Linien) in 6 Szenen nebeneinander in 2 Reihen auf reinweißem Hintergrund, ohne Schatten, ohne Text, ohne Logo, jede Szene mit Abstand:
1. trägt das Geschirr aus Bild 2, die LED leuchtet grün, er läuft fröhlich
2. sitzt nachts auf einem kleinen Stück dunklem Gehweg, das Geschirr leuchtet hell grün
3. schaut stolz, das Geschirr leuchtet blau
4. wird mit dem Handstück aus Bild 3 gebürstet und genießt es mit geschlossenen Augen
5. sitzt neben einem großen Haufen ausgekämmter Hundehaare auf dem Boden und schaut schuldig
6. liegt entspannt und gepflegt neben dem Pflegeset aus Bild 3
```
